# Add Motion Effects

Add professional motion effects to existing components or pages.

## Effect Types

Parallax - Background parallax scrolling, multi-layer depth
Scroll - Fade in, slide in, scale up, stagger animations
Hover - Scale, color transitions, shadows, underlines
Page Transitions - Fade, slide, loading states
Micro-interactions - Button feedback, form focus, toggles

## Premium Levels

Basic - Simple fades, gentle hover lifts
Standard - Scroll-triggered, staggered reveals, smooth transitions
Premium - Parallax, 3D transforms, magnetic buttons

## Rules

1. Performance first - use CSS transforms and opacity
2. Respect reduced motion - include prefers-reduced-motion
3. Consistent timing - 150ms, 200ms, 300ms, 500ms scale
4. Easing - ease-out for enters, ease-in for exits

## Libraries

React/Next.js: Framer Motion or CSS transitions
Flutter: AnimationController or flutter_animate
